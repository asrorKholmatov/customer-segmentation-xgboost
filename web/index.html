    Reading these numbers honestly

    Segments in this dataset overlap a lot — two customers with identical profiles often sit in different segments — so no model gets near 100%. Published solutions for this Kaggle dataset top out around 50–55% accuracy. SegmentIQ is about 2× better than guessing, and is most reliable for segment D (young, single, low spenders). Use the confidence score: predictions above ~60% are noticeably more trustworthy.

    How it works

    1. 1

      Data

      Kaggle “Customer Segmentation” dataset — 8,068 customers of an automobile company with segments assigned by the sales team.

    2. 2

      Features

      Yes/No fields become 0/1, spending becomes Low < Average < High, profession and category are one-hot encoded. Missing values stay missing.

    3. 3

      Training

      XGBoost multi-class classifier; depth, learning rate and leaf size tuned with 5-fold cross-validation, tree count by early stopping.

    4. 4

      In your browser

      The trained trees are exported to JSON and evaluated in JavaScript — identical results to Python, no server needed.
